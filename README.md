# A股大亨 · 手机版

用**真实 A 股行情**和 **100 万虚拟资金**炒股的单机网页游戏。纯前端，没有服务器：
行情由浏览器直接连接腾讯/东方财富公开接口，存档放在浏览器 localStorage。

- 规则：T+1、100 股一手、涨跌停、佣金万 2.5（最低 5 元）+ 卖出印花税万 5
- 玩法：自选股、实时分时、买卖、赛季目标 150 万、13 个成就
- 存档备份：页面底部「导出存档 / 导入存档」，换手机或清缓存前先导出一份
- 支持添加到主屏幕（PWA），手机全屏运行

打开 `index.html` 即可玩，或部署到任意静态托管。

> 仅供娱乐学习，不构成投资建议。
